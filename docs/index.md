# Action Service

Action Service хранит действия пользователя и передаёт их в надёжный workflow. Репозиторий не
содержит реализацию конкретной оплаты, встречи или задачи Jira: это будет спроектировано вместе с
бизнес-сценариями.

Текущее состояние: PostgreSQL, Flyway, jOOQ, outbox и Temporal worker. После подтверждения worker
вызывает `create_event` через MCP Gateway и сохраняет `eventId`; полный контейнерный путь собирается в
следующем этапе репозитория `deploy`.
