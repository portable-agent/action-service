# ADR-0001: jOOQ вместо JPA

Статус: принято.

## Контекст

Команде нужен явный SQL, понятная структура обычного MVC и контроль запросов PostgreSQL. JPA и
Hibernate скрывают часть работы с базой и не подходят выбранному стилю проекта.

## Решение

Используем Spring Boot jOOQ starter. Схема создаётся Flyway. jOOQ генерирует типобезопасные классы
из Flyway SQL во время сборки. Repository-классы используют `DSLContext` и возвращают обычные
модели.

## Последствия

- SQL и обращения к полям видны в коде.
- Изменение схемы быстро ломает компиляцию несовместимого repository.
- Маппинг строк БД в модели пишем явно.
- Сгенерированный код не коммитим.
